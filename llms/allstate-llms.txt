# Allstate

> Allstate is a personal lines property and casualty insurer in the United States, offering auto, home,
> renters, condo, motorcycle, boat, life, identity and business insurance through exclusive agents, call
> centers and direct digital channels. Allstate operates a partner API program, but it is not a public
> developer platform: the Allstate Developer Portal is credential-gated and no machine-readable API
> contract (OpenAPI, GraphQL SDL, AsyncAPI, gRPC or WSDL) is published to the open web.

## Important for agents

- There is **no publicly callable Allstate API**. As of 2026-09-01 no OpenAPI, Swagger, GraphQL SDL,
  AsyncAPI, `.proto` or WSDL document could be retrieved from any Allstate host.
- `developer.allstate.com` answers HTTP 200 to every path with an identical login page. A 200 from that
  host is **not** evidence that a document exists. Do not treat responses from it as content.
- `www.allstate.com` serves no `/.well-known/` discovery documents: `security.txt`,
  `openid-configuration`, `oauth-authorization-server`, `oauth-protected-resource`, `api-catalog`,
  `ai-plugin.json` and `agent-card.json` all return 404.
- There is no Allstate MCP server, no A2A agent card, no public status page and no published rate limits
  or API pricing.
- Obtaining API access is a business-development process: partners submit a contact form and Allstate
  initiates a call. It is not self-serve and cannot be completed by an agent.

## API access (gated)

- [Allstate Developer Portal](https://developer.allstate.com/): partner login required. The landing page
  states "Welcome to DevPortal. Log in to access the APIs" and declares the host a private computer
  facility restricted to specifically authorized users.
- [Embedded Solutions (B2B)](https://www.allstate.com/b2b/embedded-insurance): the commercial entry point
  for embedding Allstate insurance products into a partner experience. Ends in a contact form; no
  technical documentation, pricing or quotas are published here.
- [Allstate for Business (B2B)](https://www.allstate.com/b2b): overview of Allstate's partner and
  distribution offerings.
